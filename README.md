# AIMD 动力学模拟模块

轨迹格式针对本项目的 AIMD XYZ 进行了专门解析：

```text
160
i =        0, time =        0.000, E =     -5325.2150529819
O   0.0000000000 0.0000000000 0.0000000000
...
160
i =        1, time =        1.000, E =     -5325.2130625402
...
```

规则：
- 每帧第一行：该帧原子总数；
- 每帧第二行：自动提取 `i`、`time`、`E`；
- 后续恰好读取 `N` 行原子坐标；
- 元素由每一行坐标的第一个字段动态识别，不预设 Pt/Ce/O；
- 元素符号自动规范化，例如 `ce`/`CE` → `Ce`，`pt`/`PT` → `Pt`；
- 所有帧原子数必须一致，否则直接报错，防止轨迹错位；
- 页面自动统计当前帧元素组成并按元素分色。

将轨迹放入 `public/aimd/` 后运行：

```bash
npm run generate:aimd
npm run dev
```

## 数据新增、修改、删除

数据表现在支持：
- 新增数据：点击“新增数据”，填写催化剂_ID、催化剂类型、掺杂金属及其他参数。
- 修改数据：每行右侧点击“编辑”，保存后立即生效。
- 删除数据：每行右侧点击“删除”，确认后立即从网页数据集中移除。

修改记录保存在浏览器 localStorage 中；不会直接修改 `src/data/catalysts.json`。基础数据保持原始文件不变，同时本地新增/修改/删除记录会在重新打开网页后恢复。
