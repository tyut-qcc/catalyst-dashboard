结构模型文件放置约定
====================

1. catalyst/ 目录
   存放催化剂本体结构（XYZ 格式），界面中展示在“催化剂结构展示”分区。
   可在其下继续建立子目录（如 Pt-CeO2/、Rh-CeO2/），目录层级会原样显示。

2. 其它顶层目录（如 CO-oxidation/、C3H6-oxidation/、NH3-SCR/）
   存放反应中间体、过渡态等结构（XYZ 格式），界面中展示在
   “反应中间体/过渡态结构展示”分区。

3. 添加、删除或修改 XYZ 文件后，在项目根目录运行以下命令刷新索引：
   npm run generate:structures

4. 仅支持 .xyz 文件；每个文件第一行可为原子数、第二行可为注释，
   也兼容直接以“元素 x y z”开头的坐标文本。
